Aspect Redis Approach My Approach What I Learned
Threading Single-threaded event loop Goroutine-per-connection + 16 shards Multi-threading only pays off with careful sharding
RDB Snapshot fork() + COW Progressive shard-by-shard fork() gives perfect snapshot but at steep memory cost
INCR Inherently atomic sync/atomic — lock-free Atomics only needed because I chose multi-threading
Key Expiry Lazy + periodic Lazy + probabilistic sampling Sampling 20 keys with 25% threshold is bounded-cost
